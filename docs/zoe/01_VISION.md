# Zoe CLI — Vision

Zoe CLI is the AI developer that understands a project before building in it. It serves developers working in an existing terminal and repository who need reliable analysis, precise edits, creation, debugging, command execution and verification.

## Product principles

- Understand workspace context before mutating files.
- Preserve exact user requirements and unrelated code.
- Ask for approval for consequential actions.
- Verify results; never report success from a write alone.
- Keep workspace and conversation memory local-first.
- Be concise, observable and dependable in a terminal.

## Non-goals

Zoe v1 is not a dashboard-first IDE, a generic chat wrapper, a clone of another coding CLI, a BYOK product, or an MCP/Skills platform.

## Differentiation and v1 success

Zoe combines repository understanding, a structured plan, constrained tools, honest verification, and a visible task state. A successful private-preview v1 lets a Windows developer sign in once, understand a repository, complete a bounded coding request, see permissions and progress, verify the outcome, interrupt safely, and receive an honest failure when verification cannot prove success.
